1. PRODUCT IDENTITY
================================================================================
NovaForge is a native iPhone AI software-engineering command center.

It is NOT a generic chatbot, scooter/game app, Voltline, social app, or desktop IDE squeezed onto a phone.

NovaForge lets a builder:
- select and understand a software project;
- state an engineering mission;
- use source-backed project context;
- run a plan -> inspect -> act -> observe -> verify loop;
- approve consequential actions;
- inspect exact tool/command/diff/test evidence;
- receive streamed AI output reliably;
- recover interrupted runs;
- preserve durable receipts;
- choose between local/private and trusted hosted inference with truthful capability/privacy semantics;
- continue useful engineering work from iPhone.

Positioning:
“A native iPhone AI software-engineering command center: a project-aware agent that can understand a repository, execute bounded engineering work with permission, prove what it changed, preserve durable receipts, and choose intelligently between private local inference and trusted hosted routes.”

Primary principle: TRUST > THEATER.
If NovaForge says something happened, evidence must exist.

EXPERIMENTAL
LEGACY
BROKEN
UNVERIFIED
REMOVED_DO_NOT_OFFER
