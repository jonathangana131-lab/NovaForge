- a terminal wrapper;
- a generic chatbot;
- a desktop IDE squeezed onto a phone;
- Voltline;

A new user should be able to create software without knowing Git exists.

DEEPEST ARCHITECTURAL PRINCIPLE:
A PROJECT MISSION BELONGS TO NOVAFORGE, NOT TO THE MODEL CONVERSATION THAT HAPPENED TO START IT.

Models, devices, cloud workers, and optional Macs are workers underneath one durable mission.
