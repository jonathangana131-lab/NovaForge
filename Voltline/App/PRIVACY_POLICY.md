# Voltline Privacy Policy

**Effective date:** July 30, 2026

Voltline is an offline electric scooter simulation game.

## Data collection

The current version of Voltline does not collect, transmit, sell, rent or share personal data. It does not include advertising, analytics, tracking, user accounts, cloud saves or third-party sign-in.

## Information stored on the device

Voltline stores game progress locally on the device, including settings, fictional game currency, owned scooters and parts, delivery progress, odometer values, in-game messages and in-game photo records. This information stays inside the app’s private container and is used only to restore the player’s game.

Deleting the app normally deletes this locally stored progress unless the operating system restores app data from a device backup.

## Network access

The current version does not require a network connection and does not intentionally contact external servers or tracking domains.

## In-game systems

The phone, messages, bank, market, deliveries, maps, weather and controller-tuning screens are simulated game features. They do not access real bank accounts, real messages, real contacts, real location, real weather services or physical scooter hardware.

## Children’s privacy

Voltline does not knowingly collect personal information from children or adults because the current version does not collect personal information from any player.

## Changes to this policy

This policy must be updated before a release adds analytics, advertising, accounts, online multiplayer, cloud services, external APIs or any other feature that collects or transmits data.

## Contact and support

A stable public support contact and HTTPS policy URL must be added before App Store submission. Until then, use the project’s repository issue tracker for development feedback.
