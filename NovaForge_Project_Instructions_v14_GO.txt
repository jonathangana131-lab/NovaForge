PRODUCT NORTH STAR:
NovaForge is an iPhone-native local-first AI creation OS, not a generic chatbot with code buttons. The normal experience is Describe -> Understand -> Forge -> Run -> Experience -> Critique -> Repair -> Polish -> Complete.

The quality target is ABOVE merely copying ChatGPT. First-party iOS/ChatGPT coherence is the floor. NovaForge must develop an original flagship-quality visual and interaction identity. The Composer, Plan Space, Full Forge mission experience, Local Model Center, Run mode, History/Time Machine, visual editing, and completion/evidence surfaces must be brainstormed, prototyped, run, screenshot-critiqued, accessibility-tested, performance-checked, and repeatedly polished until they feel exceptional rather than merely competent.

FLAGSHIP COMPOSER / PLAN SPACE:
The Composer is not a plain text field. Treat it as the front door to the creation OS. It should adapt fluidly around the user's intent, reveal only material controls, support visual Plan Space decisions/previews, Decide for me, Autonomy, Build Depth, Intelligence, Privacy, Creativity and Refactor Risk, and keep one obvious next action that morphs with state. Avoid card soup, generic AI gradients, giant chrome, debug aesthetics, and settings-form UX.

FULL FORGE AUTONOMY:
Full Forge must be a real evidence-backed autonomous mode that can plan, implement, build, run, interact/play, inspect, test, visually critique, repair, regression-test, accessibility/performance-test, polish, and loop until the machine-readable Completion Constitution is genuinely satisfied or a real blocker requires the user. A model saying `done` is never completion evidence.

AUTONOMOUS GAME COMPLETION:
Forge Runtime should expose safe semantic self-play/playtest inputs. NovaForge should be able to run generated games, operate them through authorized controls, test goal paths and edge cases, inspect screenshots/runtime state, detect defects, patch, rerun, compare, and repeat until accepted. Completion must bind real build/runtime/test/visual/accessibility/performance receipts.

LOCAL AI IS PRIMARY:
Treat local models as a core product and the main NovaForge superpower, not a side settings page. Build a device-aware Local Model Fabric with tiny router/compactor/encoder models, a fast local agent/tool tier, deeper coding/reasoning tiers where exact-device evidence permits, and clearly labeled experimental sparse/beyond-RAM tiers. Local Only must never silently use cloud.

FORGE COMPACT / MEMORY SYSTEM:
Prioritize long autonomous local missions through a measured compaction system using combinations of:
- low-bit model profiles;
- native low-bit/ternary architectures where supported;
- quantized/adaptive KV cache;
- Project Capsules instead of replaying raw chat history;
- structured Project Brain retrieval;
- exact-prefix/KV reuse where valid;
- speculative decoding;
- memory-pressure-aware runtime governors;
- isolated flash-backed cold-weight/neuron loading experiments;
- sparse/MoE expert paging/streaming experiments;
- CPU + Metal + flash scheduling research.
