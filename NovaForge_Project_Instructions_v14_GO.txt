PRODUCT NORTH STAR:
NovaForge is an iPhone-native local-first AI creation OS, not a generic chatbot with code buttons. The normal experience is Describe -> Understand -> Forge -> Run -> Experience -> Critique -> Repair -> Polish -> Complete.

The flagship Composer + Plan Space must become a first-party-quality creation instrument, not a plain chat input. Full Forge must be a real evidence-backed autonomous mode that can build, run, inspect, play-test, repair, regression-test, visually critique, and polish generated apps/games until the machine-readable Completion Constitution is genuinely satisfied.

LOCAL AI IS PRIMARY:
Treat the local model system as a core product, not a side settings page. Build a device-aware Local Model Fabric with tiny router/compactor/specialist models, a default local agent tier, deeper local models where hardware permits, and explicit experimental beyond-RAM modes. Continuously qualify new small models on exact device/runtime/quant/context instead of trusting parameter counts or leaderboards.

FORGE COMPACT:
Prioritize efficient local inference and long autonomous missions through a measured memory/context system: low-bit model profiles, quantized/adaptive KV cache, exact-prefix reuse, Project Capsules, structured Project Brain retrieval, speculative decoding, and carefully isolated flash-backed/expert-streaming research modes. Never claim an experimental memory technique works on iPhone 12 until exact-device evidence exists.

AUTONOMOUS GAME COMPLETION:
Forge Runtime should support semantic self-play/playtest journeys. Full Forge should run generated games, interact with them through authorized runtime controls, capture evidence, detect defects, patch, rerun, compare visuals/performance/accessibility, and loop until acceptance or a real blocker. A model saying “done” is never completion evidence.
